
# Investment (M09, spec §13)
#
# Where capital comes from (Q34-Q36, Q60):
#   Sector capital, sector_capital@<sector> (country): what each sector keeps of its profit (sectors_update, scaled by
#     incentives, Q39), less the share the financial laws send to the general pool (sector_capital_mobility, §13.2).
#   The general pool, investment_fund (country): that share of retained earnings, pops' investment (pops_investment, Q60),
#     the government's development fund (development_fund_spending, Q122) and content (add_investment_fund). Bank
#     credit is live (M11); foreign capital and currency erosion follow in later milestones.
#   The infrastructure fund, infrastructure_fund (country): the government's infrastructure line, which builds railways
#     and ports where states are short of them, whatever their ROI (Q122).
#
# Each month, with no state loop of its own:
#   1. investment_prepare (country, before the state loop): clears last month's opportunities, pauses the construction
#      of sectors over their debt limit, and picks the sectors that look for a new state (investment_search).
#   2. investment_state_opportunities (state, in the state loop): each state-industry's opportunity, from last month's
#      accounts, and the best new state for each sector on the search list.
#   3. investment_monthly (country, after sectors_update): the pools take in the month's money and pay construction
#      bills, then fund the month's opportunities, best tier first. What's funded starts at once.
#
# Opportunities, one per state-industry a month, and none while it's building or retooling, since adding to a project
# only delays it (§13.5, Strat 2026-11-14). On the state, keyed by the industry:
#   opportunity_type@ - 1 expansion (an existing plant, a new state, or a sector new to the country), 2 PM upgrade,
#     3 AM upgrade (Q38), 4 prospecting (Q30), 5 infrastructure (Q122)
#   opportunity_tier@ - ROI tier (§13.4). ROI is a year's operating profit over a level's full cost (construction plus
#     investment cost): 1 Exceptional above global.investment_tier_roi^0 (20%), 2 Good above ^1 (10%), 3 Fair above ^2
#     (5%), 4 Marginal above ^3 (-5%). Anything lower isn't an opportunity. Infrastructure is 5, whatever its ROI
#   opportunity_size@ - levels to build (expansions and infrastructure)
#   opportunity_cost@ - its capital cost: headroom x construction cost for expansions (Strat 2026-11-14), the retooling
#     cost of the whole plant for upgrades, and the prospecting cost
#   The controller lists them by tier: investment_states@<tier> and investment_industries@<tier>, parallel arrays.
#   sector_opportunity_value@<sector>^<tier - 1> adds up each sector's by tier: what it can absorb.
# Expansions (Q119, Q120): a sector expands while its target utilisation is above global.investment_target_utilisation
#   (80%). A state-industry may build size x (its utilisation / 80% - 1), within its known deposits (RGOs), the free
#   arable land (farms) and the free labour: the unemployed, peasants, and global.investment_employed_share of the
#   employed, working and middle class, over its employed per level. A new state starts with
#   global.investment_new_plant_size levels, at the sector's newest methods.
#
# Who pays (Q117, Q118, Q121). Tier by tier, best first:
#   - Indivisible projects are funded whole first, in the order found: upgrades from the sector's capital only (Q38),
#     prospecting from the sector's capital, then the general pool (Q30).
#   - Expansions are funded pro rata by sector (Q125). Each sector's capital pays the investment cost
#     (global.start_construction_cost_multiplier, 25%) of as much of its own as it can. The general pool funds the same
#     share of every sector's remainder, at full cost: the investment cost, and the construction cost, which goes into the
#     sector's construction reserve (sector_construction_reserve@) for the bills. Within a sector the money funds whole
#     projects in the order found. One it can only part-fund needs the sector's minimum (sector_investment_min@, Q126):
#     global.investment_min_project_start levels in the month after the sector's last start (sector_last_investment@, a
#     month index, 0 at game start), falling global.investment_min_project_step a month to global.investment_min_project.
#     Pool money a sector declines goes to the tier's declined projects in the order found, and what's still left waits
#     for next month instead of funding a worse tier.
#   - Construction bills (the goods, over the build time) come out of the reserve, then the sector's capital, then
#     sector bank debt (sector_debt@), with interest since M11 (Q118). A sector whose debt is above
#     global.sector_debt_limit x the value of its plants, built and being built (sector_asset_value@), pauses its
#     construction (no goods bought, no progress) and starts nothing new. Retained earnings repay debt first.
#   - Infrastructure is funded whole, in the order found, at full cost from the infrastructure fund.
#   What's built belongs to the sector's generic owner (financer 0), whoever paid (Q37).
#
# Companies (M10, _economy_companies.txt): in each tier, before the sectors, each company funds its own industry's
# expansions, new plants and prospects from its treasury, and what it builds is its own (companies_fund_tier, Q132). Then
# the month's founding, if its seed is in this tier, from the general pool (company_found_fund, Q137). What a company
# starts is closed to the sectors.
#
# Market headroom (Q147, Q148): expansions and new plants, by companies, sectors and the pool, are cut to what the market
# can still take before a good's price falls below base (investment_headroom_update, investment_sector_headroom). Each
# country's funding uses it up for the members after it.
# Surplus capital (Q149, Q150): after the month's funding, a company's treasury and a sector's capital above their reserve
# go out as dividends (companies_payout_monthly, investment_surplus_payout).


	calculate_investment_appetite = {
		# Inputs (temp):
		#   incentives_temp         - modifier@incentives_modifier (base 100)
		# Output (temp):
		#   investment_appetite_temp

		set_temp_variable = {
			incentives_mod_temp = {
				value = incentives_temp
				add = 200
			}
		}
		set_temp_variable = {
			investment_appetite_temp = {
				value = incentives_temp
				multiply = 3
				divide = incentives_mod_temp
				max = 0
				min = 2
			}
		}

		# Pool-overhang damping: if the fund is accumulating undeployed capital (can't put money to work),
		# pops throw in less. overhang = investment_fund / monthly target spend (months of idle capital).
		set_temp_variable = { pool_damping_temp = {
			value = controller:investment_fund
			if = { limit = { value = controller:gdp_amount greater_than = 0 }
				divide = controller:gdp_amount
				multiply = global.investment_pool_tolerance
				multiply = -1
				add = 1
			}
			else = {
				multiply = 0
			}
			clamp = { min = global.investment_pool_appetite_floor  max = 1 }
		} }
		multiply_temp_variable = { investment_appetite_temp = pool_damping_temp }
	}
	investment_fund_update = {
		# Country scope. The general pool's income this month, for the budget screen after a tax change: pops' investment,
		# the retained earnings moved in, and the development fund. investment_monthly moves the money
		set_variable = { investment_fund_income = { value = pops_investment add = investment_retained_transfer add = development_fund_spending } }
	}


# Market headroom (Q147, Q148)
	investment_headroom_update = {
		# Market leader scope. Runs once a month, after prices move (_advance_time). investment_headroom@<good>: how much more of
		# each good the market can take before its price falls below base: demand less supply, trade included (get_price), less
		# what the construction under way in every member's sectors will make, a level at its sector's newest PM at full
		# production (investment_level_bundles). Each member's expansions and new plants use it up when they're funded, in rank
		# order (investment_monthly)
		for_each_loop = {
			array = global.resource_token_array
			value = r_type
			set_variable = { investment_headroom@var:r_type = { value = demand@var:r_type subtract = supply@var:r_type } }
		}
		set_temp_variable = { hr_leader = THIS }
		for_each_scope_loop = {
			array = market_countries
			for_each_loop = {
				array = sectors
				value = s_token
				if = {
					limit = { check_variable = { sector_construction@var:s_token > 0 } }
					investment_level_bundles = yes
					multiply_temp_variable = { hr_bundles = sector_construction@var:s_token }
					investment_headroom_take = yes
				}
			}
		}
	}
	investment_level_bundles = {
		# Country scope. Input: s_token. Output: hr_bundles, the bundles of base production a level of the sector makes at its
		# newest PM at full production, before modifiers
		set_temp_variable = { hr_pm = latest_production_method@var:s_token }
		set_temp_variable = {
			hr_bundles = {
				value = global.pm_output_amount@var:hr_pm
				multiply = global.building_production_multiplier@var:s_token
				multiply = global.building_base_employees@var:s_token
			}
		}
	}
	investment_headroom_take = {
		# Any scope. Inputs: s_token, hr_bundles (bundles of its base production), hr_leader (the market leader). Takes what
		# they make of each good off the market's headroom
		for_each_loop = {
			array = global.building_base_production@var:s_token
			value = r_type
			index = hr_i
			set_temp_variable = { hr_amount = global.building_base_production_amount@var:s_token^hr_i }
			multiply_temp_variable = { hr_amount = hr_bundles }
			subtract_from_variable = { hr_leader:investment_headroom@var:r_type = hr_amount }
		}
	}
	investment_sector_headroom = {
		# Country scope. Input: s_token. sector_headroom@<sector>: how many levels of it its market can still take this month
		# before its goods' prices fall below base, from the market leader's investment_headroom@<good>: each good's headroom
		# over what a level makes of it, weighted by the good's share of a level's value at base prices. A sector that makes no
		# goods (railways and ports) isn't limited. sector_headroom_used@ counts what this month's funding takes
		set_variable = { sector_headroom_used@var:s_token = 0 }
		investment_level_bundles = yes
		set_temp_variable = { hr_levels_temp = 0 }
		set_temp_variable = { hr_value_temp = 0 }
		if = {
			limit = { check_variable = { hr_bundles > 0 } }
			for_each_loop = {
				array = global.building_base_production@var:s_token
				value = r_type
				index = hr_i
				set_temp_variable = { hr_amount = global.building_base_production_amount@var:s_token^hr_i }
				set_temp_variable = { hr_room_temp = inv_leader:investment_headroom@var:r_type }
				if = {
					limit = { check_variable = { hr_amount > 0 } }
					set_temp_variable = { hr_good_value_temp = { value = hr_amount multiply = global.base_price@var:r_type } }
					add_to_temp_variable = { hr_levels_temp = { value = hr_room_temp divide = hr_amount divide = hr_bundles multiply = hr_good_value_temp } }
					add_to_temp_variable = { hr_value_temp = hr_good_value_temp }
				}
			}
		}
		set_variable = { sector_headroom@var:s_token = global.investment_headroom_unlimited }
		if = {
			limit = { check_variable = { hr_value_temp > 0 } }
			set_variable = { sector_headroom@var:s_token = { value = hr_levels_temp divide = hr_value_temp max = 0 } }
		}
	}


# Before the state loop
	investment_prepare = {
		# Country scope. Runs once a tick, after sectors_monthly
		# - Clears last month's opportunities: the lists, and the state records they point to
		# - sector_construction_paused@<sector>: 1 while the sector's debt is above its limit (Q118)
		# - investment_search: the sectors that look for a new state this month (§13.5). First the sectors that want to grow,
		#   best margin first, then, while the general pool holds global.investment_new_sector_min_pool, the sectors new to
		#   the country with the best ROI at the capital's wage. At most global.investment_search_base +
		#   global.investment_search_per_state per controlled state, and global.investment_search_max
		# - investment_level_*@<sector>: what a level at the sector's newest methods makes and costs (investment_economics),
		#   for the states to price a new plant with
		set_temp_variable = { inv_country = THIS }
		for_each_loop = {
			array = global.investment_lists
			value = inv_t
			for_each_loop = {
				array = investment_states@var:inv_t
				value = inv_state
				index = inv_k
				set_temp_variable = { inv_b = investment_industries@var:inv_t^inv_k }
				var:inv_state = {
					clear_variable = opportunity_tier@var:inv_b
					clear_variable = opportunity_type@var:inv_b
					clear_variable = opportunity_size@var:inv_b
					clear_variable = opportunity_cost@var:inv_b
				}
			}
			clear_array = investment_states@var:inv_t
			clear_array = investment_industries@var:inv_t
		}

		clear_array = investment_search
		clear_array = investment_search_key

		# This month's seed for a new company (company_found_candidate), looked for while the general pool has money (Q137)
		set_variable = { company_found_tier = 0 }
		set_variable = { company_found_roi = -1 }
		set_temp_variable = { inv_found_open = 0 }
		if = {
			limit = { check_variable = { investment_fund > 0 } }
			set_temp_variable = { inv_found_open = 1 }
		}
		set_temp_variable = { inv_found_n = companies^num } # Each company the country has makes the next harder to found (Q151)
		set_temp_variable = { inv_found_pace = { value = global.company_found_growth pow = inv_found_n } }

		set_temp_variable = { inv_search_n = num_controlled_states }
		set_temp_variable = {
			inv_search_n = {
				value = inv_search_n
				multiply = global.investment_search_per_state
				add = global.investment_search_base
				min = global.investment_search_max
			}
		}
		for_each_loop = {
			array = sectors
			value = s_token
			# Upgrades price the sector's newest methods, which the PM/AM cache holds only once a state-industry uses them
			set_temp_variable = { cache_token = latest_production_method@var:s_token }
			if = {
				limit = {
					NOT = { check_variable = { cache_token = 0 } }
					NOT = { is_in_array = { methods_in_use = cache_token } }
				}
				cache_method_calc = yes
			}
			set_temp_variable = { cache_token = latest_automation_method@var:s_token }
			if = {
				limit = {
					NOT = { check_variable = { cache_token = 0 } }
					NOT = { is_in_array = { methods_in_use = cache_token } }
				}
				cache_method_calc = yes
			}

			bank_sector_assets_update = yes
			set_variable = { sector_construction_paused@var:s_token = 0 }
			if = { # The limit is a share of what its plants, built and being built, would cost at its newest methods
				limit = { check_variable = { sector_debt@var:s_token > 0 } }
				bank_sector_default_monthly = yes
				set_temp_variable = { inv_limit_temp = { value = sector_asset_value@var:s_token multiply = global.sector_debt_limit } }
				if = {
					limit = { check_variable = { sector_debt@var:s_token > inv_limit_temp } }
					set_variable = { sector_construction_paused@var:s_token = 1 }
				}
			}
			# Sectors that want to grow look for new states too. Transport is left to the infrastructure fund
			if = {
				limit = {
					check_variable = { sector_size@var:s_token > 0 }
					check_variable = { sector_utilisation@var:s_token > global.investment_target_utilisation }
					check_variable = { sector_construction_paused@var:s_token = 0 }
					NOT = { check_variable = { global.building_type@var:s_token = 2 } }
				}
				set_temp_variable = { inv_key_temp = sector_margin@var:s_token }
				investment_search_add = yes
			}
		}

		# Sectors new to the country wait for outside money (§13.3), so they're looked at only when the pool has some
		if = {
			limit = {
				check_variable = { investment_search^num < inv_search_n }
				check_variable = { investment_fund > global.investment_new_sector_min_pool }
			}
			clear_array = investment_new_sectors
			clear_array = investment_new_sectors_key
			set_temp_variable = { inv_util = { value = global.sector_utilisation_start divide = 100 } }
			investment_util_output = yes
			capital_scope = { set_temp_variable = { inv_wage_temp = base_wage } }
			for_each_loop = {
				array = global.investment_new_sector_tokens
				value = inv_sector
				if = {
					limit = {
						NOT = { check_variable = { sector_size@var:inv_sector > 0 } }
						NOT = { check_variable = { sector_construction@var:inv_sector > 0 } }
						NOT = { check_variable = { latest_production_method@var:inv_sector = 0 } }
						OR = {
							check_variable = { global.building_tech_unlock@var:inv_sector = 0 }
							has_tech = var:global.building_tech_unlock@var:inv_sector
						}
						OR = { # An RGO needs deposits someone has found
							NOT = { check_variable = { global.building_rgo@var:inv_sector > 0 } }
							check_variable = { sector_known_deposits@var:inv_sector > 0 }
						}
					}
					investment_level_calc = yes
					# At the capital's wage, with no transport shortage and land and deposits of quality 1
					set_temp_variable = {
						inv_profit_temp = {
							value = inv_level_revenue
							subtract = inv_level_input
							multiply = inv_util_output
							subtract = { value = inv_level_payroll multiply = inv_wage_temp multiply = inv_util }
							subtract = inv_level_maintenance
						}
					}
					investment_roi_calc = yes
					if = {
						limit = { check_variable = { inv_tier_temp > 0 } }
						set_temp_variable = { inv_key_temp = inv_roi_temp }
						add_to_array = { investment_new_sectors = inv_sector }
						add_to_array = { investment_new_sectors_key = inv_key_temp }
					}
				}
			}
			# The best of them fill the search list's free places
			while_loop_effect = {
				limit = {
					check_variable = { investment_search^num < inv_search_n }
					check_variable = { investment_new_sectors^num > 0 }
				}
				set_temp_variable = { inv_best_k = 0 }
				for_each_loop = {
					array = investment_new_sectors_key
					value = inv_key_temp
					index = inv_k
					set_temp_variable = { inv_best_key = investment_new_sectors_key^inv_best_k }
					if = {
						limit = { check_variable = { inv_key_temp > inv_best_key } }
						set_temp_variable = { inv_best_k = inv_k }
					}
				}
				set_temp_variable = { inv_sector = investment_new_sectors^inv_best_k }
				add_to_array = { investment_search = inv_sector }
				add_to_array = { investment_search_key = -1 }
				remove_from_array = { array = investment_new_sectors index = inv_best_k }
				remove_from_array = { array = investment_new_sectors_key index = inv_best_k }
			}
		}

		# What a new plant of each searching sector makes and costs, and where its best new state stands so far
		for_each_loop = {
			array = investment_search
			value = inv_sector
			investment_level_calc = yes
			set_variable = { investment_level_revenue@var:inv_sector = inv_level_revenue }
			set_variable = { investment_level_input@var:inv_sector = inv_level_input }
			set_variable = { investment_level_payroll@var:inv_sector = inv_level_payroll }
			set_variable = { investment_level_jobs@var:inv_sector = inv_level_jobs }
			set_variable = { investment_level_maintenance@var:inv_sector = inv_level_maintenance }
			set_variable = { investment_level_cost@var:inv_sector = inv_level_cost }
			set_variable = { investment_new_size@var:inv_sector = 0 }
			set_variable = { investment_new_roi@var:inv_sector = -1 }
		}
	}
	investment_search_add = {
		# Country scope. Input: s_token, inv_key_temp (its margin). Puts the sector on the search list, highest key first,
		# and drops the lowest past inv_search_n
		set_temp_variable = { inv_break_temp = 0 }
		for_each_loop = {
			array = investment_search_key
			value = inv_other_key
			index = inv_k
			break = inv_break_temp
			if = {
				limit = { check_variable = { inv_key_temp > inv_other_key } }
				add_to_array = { array = investment_search value = s_token index = inv_k }
				add_to_array = { array = investment_search_key value = inv_key_temp index = inv_k }
				set_temp_variable = { inv_break_temp = 1 }
			}
		}
		if = {
			limit = { check_variable = { inv_break_temp = 0 } }
			add_to_array = { investment_search = s_token }
			add_to_array = { investment_search_key = inv_key_temp }
		}
		if = {
			limit = { check_variable = { investment_search^num > inv_search_n } }
			set_temp_variable = { inv_last_temp = { value = investment_search^num subtract = 1 } }
			remove_from_array = { array = investment_search index = inv_last_temp }
			remove_from_array = { array = investment_search_key index = inv_last_temp }
		}
	}
	investment_level_calc = {
		# Country scope. Input: inv_sector. Its newest methods' per-level figures (investment_economics), working out their
		# market values first if the country's PM/AM cache doesn't hold them (a sector or method no state-industry uses yet)
		set_temp_variable = { inv_pm = latest_production_method@var:inv_sector }
		set_temp_variable = { inv_am = latest_automation_method@var:inv_sector }
		if = {
			limit = { NOT = { is_in_array = { sectors = inv_sector } } }
			set_temp_variable = { cache_token = inv_sector }
			cache_sector_calc = yes
		}
		if = {
			limit = { NOT = { is_in_array = { methods_in_use = inv_pm } } }
			set_temp_variable = { cache_token = inv_pm }
			cache_method_calc = yes
		}
		if = {
			limit = {
				NOT = { check_variable = { inv_am = 0 } }
				NOT = { is_in_array = { methods_in_use = inv_am } }
			}
			set_temp_variable = { cache_token = inv_am }
			cache_method_calc = yes
		}
		investment_economics = yes
	}
	investment_economics = {
		# Country scope. Input: inv_sector, inv_pm, inv_am - a sector and the methods a level of it would use
		# What one level makes and costs a month at full production, from the PM/AM cache at this country's prices and
		# modifiers, as industry_production_update works it out, before the state's Infrastructure Efficiency, wage, land or
		# deposit quality and economy of scale. Railways' and ports' pay for transport isn't in it
		# Outputs: inv_level_revenue, inv_level_input, inv_level_payroll (wage-weighted workers: times the base wage),
		#   inv_level_jobs (K workers), inv_level_maintenance, inv_level_cost (the construction cost)
		set_temp_variable = { inv_employees_temp = global.building_base_employees@var:inv_sector }
		set_temp_variable = {
			inv_common_temp = {
				value = 1
				add = industry_throughput_factor@var:inv_sector
				multiply = {
					value = 1
					add = pm_throughput_factor@var:inv_pm
					add = pm_throughput_factor@var:inv_am
				}
				multiply = inv_employees_temp
			}
		}
		set_temp_variable = {
			inv_level_revenue = {
				value = market_output_value@var:inv_sector
				multiply = global.pm_output_amount@var:inv_pm
				multiply = global.building_production_multiplier@var:inv_sector
				multiply = inv_common_temp
				multiply = { value = 1 add = industry_output_factor@var:inv_sector }
			}
		}
		set_temp_variable = {
			inv_level_input = {
				value = method_input_cost@var:inv_pm
				add = method_input_cost@var:inv_am
				multiply = inv_common_temp
				multiply = { value = 1 add = industry_input_factor@var:inv_sector }
			}
		}
		set_temp_variable = { inv_pm_jobs_temp = { value = 1 add = pm_employment_factor@var:inv_pm } }
		set_temp_variable = { inv_am_jobs_temp = { value = 1 add = pm_employment_factor@var:inv_am } }
		set_temp_variable = {
			inv_working_temp = {
				value = global.pm_workforce_working@var:inv_pm
				multiply = inv_pm_jobs_temp
				add = { value = global.pm_workforce_working@var:inv_am multiply = inv_am_jobs_temp }
				max = 0
			}
		}
		set_temp_variable = {
			inv_middle_temp = {
				value = global.pm_workforce_middle@var:inv_pm
				multiply = inv_pm_jobs_temp
				add = { value = global.pm_workforce_middle@var:inv_am multiply = inv_am_jobs_temp }
				max = 0
			}
		}
		set_temp_variable = { inv_level_jobs = { value = inv_working_temp add = inv_middle_temp multiply = inv_employees_temp } }
		set_temp_variable = {
			inv_level_payroll = {
				value = inv_working_temp
				multiply = global.wage_multiplier@token:working_class
				add = { value = inv_middle_temp multiply = global.wage_multiplier@token:middle_class }
				multiply = inv_employees_temp
			}
		}
		set_temp_variable = {
			inv_level_maintenance = {
				value = global.pm_construction_value@var:inv_pm
				add = global.pm_construction_value@var:inv_am
				multiply = global.maintenance_rate
				multiply = inv_employees_temp
				multiply = { value = 1 add = modifier@regulatory_burden_factor }
			}
		}
		set_temp_variable = {
			inv_level_cost = {
				value = method_construction_cost@var:inv_pm
				add = method_construction_cost@var:inv_am
				multiply = inv_employees_temp
				multiply = { value = 1 add = industry_construction_cost_factor }
			}
		}
	}
	investment_util_output = {
		# Any scope. Input: inv_util (0-1). Output: inv_util_output, the share of full output a plant makes when it offers
		# inv_util of its jobs and fills them, as industry_update_employment works it out
		set_temp_variable = {
			inv_util_output = {
				value = inv_util
				multiply = inv_util
				multiply = inv_util
				multiply = -0.2
				add = 1.2
				multiply = inv_util
			}
		}
	}
	investment_roi_calc = {
		# Any scope. Input: inv_profit_temp (a level's operating profit a month), inv_level_cost (its construction cost)
		# Outputs: inv_roi_temp, a year's profit over the level's full cost (construction plus investment cost), and
		#   inv_tier_temp, 1 (Exceptional) to 4 (Marginal), or 0 below Marginal (§13.4)
		set_temp_variable = { inv_roi_temp = 0 }
		if = {
			limit = { check_variable = { inv_level_cost > 0 } }
			set_temp_variable = {
				inv_roi_temp = {
					value = inv_profit_temp
					multiply = 12
					divide = inv_level_cost
					divide = { value = 1 add = global.start_construction_cost_multiplier }
				}
			}
		}
		set_temp_variable = { inv_tier_temp = 0 }
		set_temp_variable = { inv_tier_break = 0 }
		for_each_loop = {
			array = global.investment_tier_roi
			value = inv_floor_temp
			index = inv_tier_i
			break = inv_tier_break
			if = {
				limit = { check_variable = { inv_roi_temp > inv_floor_temp } }
				set_temp_variable = { inv_tier_temp = { value = inv_tier_i add = 1 } }
				set_temp_variable = { inv_tier_break = 1 }
			}
		}
	}


# In the state loop
	investment_state_opportunities = {
		# State scope, in the state loop after industries_monthly. Finds this month's opportunity for each of the state's
		# working state-industries (investment_industry_opportunity), this state's place as a new home for each sector on
		# the controller's search list, and the railway or port it's short of, while the infrastructure fund has money
		# Free labour (Q119): the unemployed, peasants, and a share of the employed, working and middle class. Each
		# opportunity found takes its workers out of it, so a state's opportunities don't count the same people twice
		set_temp_variable = {
			inv_labour_temp = {
				value = pops_workforce_balance@token:working_class
				max = 0
				add = { value = pops_workforce_balance@token:middle_class max = 0 }
				add = pops_workforce@token:peasants
				add = {
					value = pops_employed@token:working_class
					add = pops_employed@token:middle_class
					multiply = global.investment_employed_share
				}
			}
		}

		# Most state-industries have nothing to offer: their sector isn't near expanding, and they use its newest methods or
		# this isn't one of the state's months to price upgrades (global.investment_upgrade_check_chance)
		set_temp_variable = { inv_expand_floor = { value = global.investment_target_utilisation subtract = global.local_utilisation_shift } }
		set_temp_variable = { inv_upgrade_month = 0 }
		set_temp_variable = { inv_roll_temp = random }
		if = {
			limit = { check_variable = { inv_roll_temp < global.investment_upgrade_check_chance } }
			set_temp_variable = { inv_upgrade_month = 1 }
		}
		# A company is founded in a state its country owns (Q135, Q138)
		set_temp_variable = { inv_found_here = 0 }
		if = {
			limit = {
				check_variable = { inv_found_open = 1 }
				is_owned_by = var:inv_country
			}
			set_temp_variable = { inv_found_here = 1 }
		}
		for_each_loop = {
			array = industries
			value = bu_token
			index = inv_ind_i
			if = { # A seed for a new company (M10, Q137)
				limit = {
					check_variable = { inv_found_here = 1 }
					NOT = { check_variable = { owner_sizes_local@var:bu_token < global.company_found_min_size } }
					is_sector = yes
					NOT = { check_variable = { global.building_type@var:bu_token = 2 } }
					check_variable = { revenue@var:bu_token > 0 }
					check_variable = { margin@var:bu_token > 0 }
				}
				company_found_candidate = yes
			}
			if = {
				limit = {
					check_variable = { size@var:bu_token > 0 }
					OR = {
						check_variable = { controller:sector_utilisation@var:bu_token > inv_expand_floor }
						AND = {
							check_variable = { inv_upgrade_month = 1 }
							OR = {
								NOT = { check_variable = { controller:latest_production_method@var:bu_token = production_method@var:bu_token } }
								NOT = { check_variable = { controller:latest_automation_method@var:bu_token = automation_method@var:bu_token } }
							}
						}
					}
					is_sector = yes
					check_variable = { construction@var:bu_token = 0 }
					check_variable = { retooling_pm@var:bu_token = 0 }
					check_variable = { controller:sector_construction_paused@var:bu_token = 0 }
					NOT = { check_variable = { margin@var:bu_token = 0 } } # No accounts yet
					NOT = { check_variable = { margin@var:bu_token < global.industry_decay_margin } } # Shrinking (industries_monthly)
				}
				investment_industry_opportunity = yes
			}
		}

		# A new home for the searching sectors: the first plant, if it can be built here and pays better than anywhere
		# found so far. investment_monthly lists each sector's best
		for_each_loop = {
			array = inv_country:investment_search
			value = inv_sector
			if = {
				limit = {
					check_variable = { size@var:inv_sector = 0 }
					check_variable = { construction@var:inv_sector = 0 }
				}
				set_temp_variable = { inv_size_temp = global.investment_new_plant_size }
				if = { # An RGO opens up the known deposits nobody works
					limit = { check_variable = { global.building_rgo@var:inv_sector > 0 } }
					set_temp_variable = { inv_size_temp = { value = known_deposits@var:inv_sector min = inv_size_temp } }
				}
				set_temp_variable = { industry_token = inv_sector }
				set_temp_variable = { size_temp = inv_size_temp }
				set_temp_variable = { inv_jobs_temp = inv_country:investment_level_jobs@var:inv_sector }
				multiply_temp_variable = { inv_jobs_temp = inv_size_temp }
				if = {
					limit = {
						check_variable = { inv_size_temp > global.investment_min_project }
						check_variable = { inv_labour_temp > inv_jobs_temp }
						can_build_industry_no_tech_check = yes
						OR = {
							NOT = { is_in_array = { global.building_token_array = inv_sector } }
							is_in_array = { buildings = inv_sector }
							check_variable = { buildings^num < 16 }
						}
					}
					set_temp_variable = { inv_util = { value = controller:sector_utilisation@var:inv_sector divide = 100 } }
					if = {
						limit = { check_variable = { inv_util = 0 } }
						set_temp_variable = { inv_util = { value = global.sector_utilisation_start divide = 100 } }
					}
					set_temp_variable = { inv_level_revenue = inv_country:investment_level_revenue@var:inv_sector }
					set_temp_variable = { inv_level_input = inv_country:investment_level_input@var:inv_sector }
					set_temp_variable = { inv_level_payroll = inv_country:investment_level_payroll@var:inv_sector }
					set_temp_variable = { inv_level_maintenance = inv_country:investment_level_maintenance@var:inv_sector }
					set_temp_variable = { inv_level_cost = inv_country:investment_level_cost@var:inv_sector }
					investment_local_profit = yes
					investment_roi_calc = yes
					set_temp_variable = { inv_best_roi = inv_country:investment_new_roi@var:inv_sector }
					if = {
						limit = {
							check_variable = { inv_tier_temp > 0 }
							check_variable = { inv_roi_temp > inv_best_roi }
						}
						set_variable = { inv_country:investment_new_state@var:inv_sector = THIS }
						set_variable = { inv_country:investment_new_roi@var:inv_sector = inv_roi_temp }
						set_variable = { inv_country:investment_new_tier@var:inv_sector = inv_tier_temp }
						set_variable = { inv_country:investment_new_size@var:inv_sector = inv_size_temp }
					}
				}
			}
		}

		# Infrastructure (Q122): a railway where the state is short of transport, and a port on the coast while the market
		# is short of shipping. One level each, at full cost from the infrastructure fund
		if = {
			limit = { check_variable = { inv_country:infrastructure_fund > 0 } }
			set_temp_variable = { inv_tier_temp = 5 }
			set_temp_variable = { inv_type_temp = 5 }
			set_temp_variable = { inv_size_temp = global.investment_new_plant_size }
			if = {
				limit = {
					check_variable = { infrastructure_efficiency < 1 }
					check_variable = { construction@token:railway = 0 }
				}
				set_temp_variable = { bu_token = token:railway }
				investment_infrastructure_record = yes
			}
			if = {
				limit = {
					is_coastal = yes
					check_variable = { controller:price_shipping_capacity > global.base_price_shipping_capacity }
					check_variable = { construction@token:port = 0 }
				}
				set_temp_variable = { bu_token = token:port }
				investment_infrastructure_record = yes
			}
		}
	}
	investment_industry_opportunity = {
		# State scope. Input: bu_token - a working state-industry of a sector, not building or retooling; inv_labour_temp
		# Its opportunity for the month, if it has one: whichever pays better of an upgrade to its sector's newest PM or AM
		# (Q38) and more of itself (Q120), or prospecting once its known deposits are all worked (Q30). Upgrades are priced
		# only in the state's upgrade months (inv_upgrade_month), since one that doesn't pay mostly stays that way
		set_temp_variable = { inv_type_temp = 0 }
		set_temp_variable = { inv_up_tier = 0 }
		set_temp_variable = { inv_sector = bu_token }

		# Upgrades: the plant as it would be against the plant as it is, here
		if = {
			limit = {
				check_variable = { inv_upgrade_month = 1 }
				NOT = { check_variable = { global.building_type@var:bu_token = 2 } } # Transport's pay isn't in investment_economics
			}
			set_temp_variable = { inv_pm = production_method@var:bu_token }
			set_temp_variable = { inv_am = automation_method@var:bu_token }
			set_temp_variable = { inv_new_method = controller:latest_production_method@var:bu_token }
			if = {
				limit = {
					NOT = { check_variable = { inv_new_method = 0 } }
					NOT = { check_variable = { inv_new_method = inv_pm } }
				}
				set_temp_variable = { inv_type_temp = 2 }
			}
			else = {
				set_temp_variable = { inv_new_method = controller:latest_automation_method@var:bu_token }
				if = {
					limit = {
						NOT = { check_variable = { inv_new_method = 0 } }
						NOT = { check_variable = { inv_new_method = inv_am } }
					}
					set_temp_variable = { inv_type_temp = 3 }
				}
			}
		}

		# Its utilisation, only if there's something to price
		set_temp_variable = { i_employment_target = 0 }
		if = {
			limit = {
				OR = {
					check_variable = { inv_type_temp > 0 }
					check_variable = { controller:sector_utilisation@var:bu_token > inv_expand_floor }
				}
			}
			industry_utilisation_calc = yes # i_employment_target, in %
			set_temp_variable = { inv_util = { value = i_employment_target divide = 100 } }
		}

		if = {
			limit = { check_variable = { inv_type_temp > 0 } }
			controller = { investment_economics = yes }
			investment_local_profit = yes
			set_temp_variable = { inv_old_profit = inv_profit_temp }
			if = {
				limit = { check_variable = { inv_type_temp = 2 } }
				set_temp_variable = { inv_pm = inv_new_method }
			}
			else = {
				set_temp_variable = { inv_am = inv_new_method }
			}
			controller = { investment_economics = yes }
			investment_local_profit = yes
			subtract_from_temp_variable = { inv_profit_temp = inv_old_profit }
			# The level's cost is the new method's construction list (get_retooling_cost)
			set_temp_variable = {
				inv_level_cost = {
					value = controller:method_construction_cost@var:inv_new_method
					multiply = global.building_base_employees@var:bu_token
					multiply = { value = 1 add = building_retooling_cost_factor }
				}
			}
			investment_roi_calc = yes
			# Held until the expansion is priced
			if = {
				limit = { check_variable = { inv_tier_temp > 0 } }
				set_temp_variable = { inv_up_type = inv_type_temp }
				set_temp_variable = { inv_up_tier = inv_tier_temp }
				set_temp_variable = { inv_up_roi = inv_roi_temp }
				set_temp_variable = { inv_up_cost = { value = inv_level_cost multiply = size@var:bu_token } }
			}
			set_temp_variable = { inv_type_temp = 0 }
		}

		# Expansions, toward the capacity the sector wants (Q120)
		if = {
			limit = { check_variable = { i_employment_target > global.investment_target_utilisation } }
			set_temp_variable = {
				inv_size_temp = {
					value = i_employment_target
					divide = global.investment_target_utilisation
					subtract = 1
					multiply = size@var:bu_token
				}
			}
			if = {
				limit = { check_variable = { global.building_rgo@var:bu_token > 0 } }
				set_temp_variable = { inv_free_temp = { value = known_deposits@var:bu_token subtract = size@var:bu_token max = 0 } }
				set_temp_variable = { inv_size_temp = { value = inv_free_temp min = inv_size_temp } }
			}
			if = {
				limit = { check_variable = { global.building_arable_land_use@var:bu_token > 0 } }
				set_temp_variable = { inv_free_temp = { value = arable_land_available divide = global.building_arable_land_use@var:bu_token max = 0 } }
				set_temp_variable = { inv_size_temp = { value = inv_free_temp min = inv_size_temp } }
			}
			set_temp_variable = { inv_per_level_temp = { value = working_employed@var:bu_token add = middle_employed@var:bu_token divide = size@var:bu_token } }
			if = {
				limit = { check_variable = { inv_per_level_temp > 0 } }
				set_temp_variable = { inv_free_temp = { value = inv_labour_temp divide = inv_per_level_temp max = 0 } }
				set_temp_variable = { inv_size_temp = { value = inv_free_temp min = inv_size_temp } }
			}

			# ROI from its trailing margin and last month's revenue, against a level at its own methods
			set_temp_variable = { inv_pm = production_method@var:bu_token }
			set_temp_variable = { inv_am = automation_method@var:bu_token }
			set_temp_variable = {
				inv_level_cost = {
					value = controller:method_construction_cost@var:inv_pm
					add = controller:method_construction_cost@var:inv_am
					multiply = global.building_base_employees@var:bu_token
					multiply = { value = 1 add = controller:industry_construction_cost_factor }
				}
			}
			set_temp_variable = { inv_profit_temp = { value = margin@var:bu_token multiply = revenue@var:bu_token divide = size@var:bu_token } }
			investment_roi_calc = yes

			if = {
				limit = {
					check_variable = { inv_tier_temp > 0 }
					check_variable = { inv_size_temp > global.investment_min_project }
					OR = {
						check_variable = { inv_up_tier = 0 }
						check_variable = { inv_roi_temp > inv_up_roi }
					}
				}
				set_temp_variable = { inv_type_temp = 1 }
				set_temp_variable = { inv_cost_temp = { value = inv_level_cost multiply = inv_size_temp } }
				investment_record = yes
				subtract_from_temp_variable = { inv_labour_temp = { value = inv_per_level_temp multiply = inv_size_temp } }
			}
			# An RGO that works all it knows of prospects for more, at the tier the expansion would have had
			else_if = {
				limit = {
					check_variable = { inv_tier_temp > 0 }
					check_variable = { global.building_rgo@var:bu_token > 0 }
					check_variable = { potential_deposits@var:bu_token > 0 }
					check_variable = { prospecting@var:bu_token = 0 }
					NOT = { check_variable = { known_deposits@var:bu_token > size@var:bu_token } }
					OR = {
						check_variable = { inv_up_tier = 0 }
						check_variable = { inv_roi_temp > inv_up_roi }
					}
				}
				set_temp_variable = { inv_type_temp = 4 }
				set_temp_variable = { inv_size_temp = 0 }
				set_temp_variable = { inv_cost_temp = prospecting_cost@var:bu_token }
				investment_record = yes
			}
		}

		# The upgrade, if it pays better or the plant has nothing else to offer
		if = {
			limit = {
				check_variable = { inv_up_tier > 0 }
				check_variable = { inv_type_temp = 0 }
			}
			set_temp_variable = { inv_type_temp = inv_up_type }
			set_temp_variable = { inv_tier_temp = inv_up_tier }
			set_temp_variable = { inv_size_temp = 0 }
			set_temp_variable = { inv_cost_temp = inv_up_cost }
			investment_record = yes
		}
	}

					add = 1

# After sectors_update
	investment_monthly = {
		# Country scope. Runs once a tick, after sectors_update and update_country_pop_stats
		# 1. Money in. Each sector's retained earnings (sector_retained@, sectors_update) repay its debt, then
		#    sector_capital_mobility of them goes to the general pool and the rest to its capital. A loss comes out of capital.
		#    The pool takes pops' investment and the development fund, and the infrastructure fund the infrastructure line.
		# 2. M11 has already paid construction before progress (bank_construction_monthly), including the final bill.
		#    A sector with nothing under way returns its unused reserve to capital. Interest is in retained earnings;
		#    operating shortfalls borrow up to collateral and available bank credit. Companies settle the same way.
		# 3. Each searching sector's best new state joins its tier.
		# 4. Funding, tier by tier (Q121): the companies' own industries first (companies_fund_tier, Q132), the month's
		#    founding (company_found_fund, Q137), indivisible projects whole, then expansions, pro rata by sector, from their
		#    sector's capital and the general pool. Then infrastructure. What's funded starts.
		# Outputs: investment_retained_transfer, investment_fund_income, investment_fund_spending (what the pool paid),
		#   investment_funded_retained (what sector capital paid), investment_funded_pool, investment_funded_companies (what
		#   companies paid, M10), companies_founded, investment_projects_started,
		#   investment_opportunities_value (the month's opportunities, at capital cost), sector_opportunity_value@<sector>
		set_temp_variable = { inv_country = THIS }
		set_temp_variable = { inv_mobility_temp = { value = global.sector_capital_mobility_base add = modifier@sector_capital_mobility clamp = { min = 0 max = 1 } } }
		set_variable = { investment_retained_transfer = 0 }
		for_each_loop = {
			array = sectors
			value = s_token
			set_temp_variable = { inv_money_temp = sector_retained@var:s_token }
			if = {
				limit = { check_variable = { inv_money_temp > 0 } }
				if = {
					limit = { check_variable = { sector_debt@var:s_token > 0 } }

					set_temp_variable = { inv_built_temp = inv_state:construction@var:inv_b }
					if = {
						limit = {

				set_temp_variable = { inv_second_walk = 0 }

	investment_sector_min = {
		# Country scope. Input: s_token, inv_now_temp. Sets the sector's minimum for a partly funded project this month (Q126):

	investment_try_expansion = {
		# Country scope. Input: inv_state, inv_b, inv_value_temp - the money for it, at capital cost (its sector's capital,
		# sector_tier_retained@, plus the pool's share); inv_second_walk - 1 if the pool's share is inv_pool_left_temp, else
		# its sector's sector_tier_pooled@
		# Starts the expansion or new plant if the money funds it whole, or else at least the sector's minimum (Q126), and only
		# as much of it as its market can still take (sector_headroom@, Q148). Sector capital pays the investment cost of as
		# much as it can, and the general pool the rest at full cost, with the construction cost into the sector's reserve (Q117)
		set_temp_variable = { inv_cost_temp = inv_state:opportunity_cost@var:inv_b }
		set_temp_variable = { inv_size_temp = inv_state:opportunity_size@var:inv_b }
		set_temp_variable = { inv_room_temp = { value = sector_headroom@var:inv_b max = 0 min = inv_size_temp } }
		if = {
			limit = { check_variable = { inv_room_temp > global.investment_min_project } }
			set_temp_variable = { inv_cost_temp = { value = inv_cost_temp multiply = inv_room_temp divide = inv_size_temp } }
			set_temp_variable = { inv_size_temp = inv_room_temp }
			set_temp_variable = { inv_value_temp = { value = inv_value_temp min = inv_cost_temp } }
			set_temp_variable = { x_temp = { value = inv_value_temp divide = inv_cost_temp multiply = inv_size_temp } }
			# Five-decimal division can leave a fully allocated project one raw level below its minimum.
			# Tolerate that residue in admission only; charge and build the actual funded amount.
			set_temp_variable = { inv_min_check_temp = { value = x_temp add = 0.0001 } }
			if = {
				limit = {
					check_variable = { x_temp > global.investment_min_project }
					OR = {
						check_variable = { inv_value_temp = inv_cost_temp }
						NOT = { check_variable = { inv_min_check_temp < sector_investment_min@var:inv_b } }
					}
				}
				set_temp_variable = { inv_paid_temp = { value = sector_tier_retained@var:inv_b min = inv_value_temp } }
				subtract_from_variable = { sector_tier_retained@var:inv_b = inv_paid_temp }
				subtract_from_temp_variable = { inv_value_temp = inv_paid_temp }
				add_to_variable = { sector_construction_remaining@var:inv_b = inv_paid_temp } # Bills its capital will pay
				multiply_temp_variable = { inv_paid_temp = global.start_construction_cost_multiplier }
				subtract_from_variable = { sector_capital@var:inv_b = inv_paid_temp }
				add_to_variable = { investment_funded_retained = inv_paid_temp }

				if = {
					limit = { check_variable = { inv_second_walk = 1 } }
					subtract_from_temp_variable = { inv_pool_left_temp = inv_value_temp }
				}
				else = {
					subtract_from_variable = { sector_tier_pooled@var:inv_b = inv_value_temp }
				}
				add_to_variable = { sector_construction_reserve@var:inv_b = inv_value_temp }
				multiply_temp_variable = { inv_value_temp = inv_full_temp }
				subtract_from_variable = { investment_fund = inv_value_temp }
				add_to_variable = { investment_fund_spending = inv_value_temp }
				add_to_variable = { investment_funded_pool = inv_value_temp }

				subtract_from_variable = { sector_headroom@var:inv_b = x_temp }
				add_to_variable = { sector_headroom_used@var:inv_b = x_temp }
				set_variable = { sector_last_investment@var:inv_b = inv_now_temp }
				set_temp_variable = { industry_token = inv_b }
				var:inv_state = { investment_start_construction = yes }
				add_to_variable = { investment_projects_started = 1 }
			}
		}
	}
	investment_fund_project = {
		# Country scope. Input: inv_state, inv_b, inv_type_temp, inv_cost_temp - an indivisible opportunity
		# Funds it whole if the money is there (Q121): an upgrade's investment cost from its sector's capital (Q38), or from
		# each owner by size if companies hold part of the plant (company_upgrade_shares, Q133); a prospect's cost from its
		# sector's capital, or else the general pool, less what a better tier declined (Q30, Q126). Retooling bills come
		# later, like construction's
		if = {
			limit = { check_variable = { inv_type_temp = 4 } }
			set_temp_variable = { inv_need_temp = inv_cost_temp }
			set_temp_variable = { inv_funded_temp = 0 }
			set_temp_variable = { inv_free_temp = { value = investment_fund subtract = inv_pool_held_temp } }
			if = {
				limit = { NOT = { check_variable = { sector_capital@var:inv_b < inv_need_temp } } }
				subtract_from_variable = { sector_capital@var:inv_b = inv_need_temp }
				add_to_variable = { investment_funded_retained = inv_need_temp }
				set_temp_variable = { inv_funded_temp = 1 }
			}
			else_if = {
				limit = { NOT = { check_variable = { inv_free_temp < inv_need_temp } } }
				subtract_from_variable = { investment_fund = inv_need_temp }
				add_to_variable = { investment_fund_spending = inv_need_temp }
				add_to_variable = { investment_funded_pool = inv_need_temp }
				set_temp_variable = { inv_funded_temp = 1 }
			}
			if = {
				limit = { check_variable = { inv_funded_temp = 1 } }
				var:inv_state = {
					set_variable = { prospecting@var:inv_b = 1 }
					set_variable = { prospecting_financier@var:inv_b = 0 }
				}
				add_to_variable = { investment_projects_started = 1 }
			}
		}
		else = {
			set_temp_variable = { inv_need_temp = { value = inv_cost_temp multiply = global.start_construction_cost_multiplier } }
			set_temp_variable = { inv_funded_temp = 0 }
			var:inv_state = { set_temp_variable = { inv_owners_temp = owner_companies@var:inv_b^num } }
			if = { # A plant companies hold part of: each owner pays its share (Q133)
				limit = { check_variable = { inv_owners_temp > 0 } }
				company_upgrade_shares = yes
			}
			else_if = {
				limit = { NOT = { check_variable = { sector_capital@var:inv_b < inv_need_temp } } }
				subtract_from_variable = { sector_capital@var:inv_b = inv_need_temp }
				add_to_variable = { investment_funded_retained = inv_need_temp }
				add_to_variable = { sector_construction_remaining@var:inv_b = inv_cost_temp } # Bills its capital will pay
				set_temp_variable = { inv_funded_temp = 1 }
			}
			if = {
				limit = { check_variable = { inv_funded_temp = 1 } }
				set_temp_variable = { financer_temp = 0 }
				set_temp_variable = { industry_token = inv_b }
				set_temp_variable = { no_cost_temp = 1 }
				set_temp_variable = { production_method_temp = 0 }
				set_temp_variable = { automation_method_temp = 0 }
				if = {
					limit = { check_variable = { inv_type_temp = 2 } }
					set_temp_variable = { production_method_temp = latest_production_method@var:inv_b }
				}
				else = {
					set_temp_variable = { automation_method_temp = latest_automation_method@var:inv_b }
				}
				var:inv_state = { retool_industry_no_update = yes }
				set_temp_variable = { no_cost_temp = 0 }
				add_to_variable = { investment_projects_started = 1 }
			}
		}
	}
	investment_start_construction = {

# Surplus capital (Q150)
	investment_surplus_payout = {
		# Country scope, at the end of investment_monthly. Pays out the generic owner's surplus capital as its sector's dividends:
		# its capital above a reserve, the bills it still has to pay beyond its construction reserve (sector_construction_remaining@
		# less sector_construction_reserve@), plus global.capital_reserve_share x the value of its plants, built and being built,
		# at its newest methods. Each state's upper class gets it next month, by generic size, with the rest of the sector's
		# dividends. A sector in debt keeps its capital
		# Outputs: sector_surplus_dividends@<sector>, sectors_surplus_dividends
		set_variable = { sectors_surplus_dividends = 0 }
		for_each_loop = {
			array = sectors
			value = s_token
			set_variable = { sector_surplus_dividends@var:s_token = 0 }
			if = {
				limit = {
					check_variable = { sector_capital@var:s_token > 0 }
					NOT = { check_variable = { sector_debt@var:s_token > 0 } }
					check_variable = { sector_generic_size@var:s_token > 0 }
				}
				set_temp_variable = { sp_pm = latest_production_method@var:s_token }
				set_temp_variable = { sp_am = latest_automation_method@var:s_token }
				set_temp_variable = {
					sp_surplus_temp = {
						value = method_construction_cost@var:sp_pm
